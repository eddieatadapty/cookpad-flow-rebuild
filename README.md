# Cookpad Growth Audit

**Live → https://eddieatadapty.github.io/cookpad-flow-rebuild/**

Five ideas to turn more Cookpad users into subscribers, each built into a clickable version of Cookpad's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they cook, then use the answer | +10–15% CR to purchase |
| 02 | Make the paywall about their search | +10–15% CR to purchase |
| 03 | Recipes first, the account at the first save | +5–10% CR to purchase |
| 04 | Show Premium inside the results it improves | +5–10% CR to purchase |
| 05 | Let ✕ lead to your import sheet, not a dead end | +3–8% CR to purchase |

Every price, rating and feature comes from Cookpad's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Cookpad. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
